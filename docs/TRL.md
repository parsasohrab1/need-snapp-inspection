# ارزیابی TRL 5

**محصول:** اسنپ‌بازرس، نسخه 0.5.0
**سطح ادعا شده:** TRL 5 برای حلقه یکپارچه اعزام تا تأیید IVR، در محیط مرتبطِ شبیه‌سازی‌شده.
**شاهد:** [`docs/validation/TRL5_REPORT.md`](validation/TRL5_REPORT.md) که با `python -m validation.run_trl5` دوباره ساخته می‌شود. آزمون‌ها در `tests/` همان قواعد را روی اجزا و روی API نمایشی پوشش می‌دهند.

## معنا در این نرم‌افزار

| TRL | معنا | وضعیت |
| --- | --- | --- |
| 3 | مسافت، رتبه‌بندی، تعرفه و ماشین حالت جدا کار می‌کنند | انجام شده |
| 4 | گیت مدارک، پذیرش انحصاری، فنس، عدم انطباق و API با آزمون پوشیده شده‌اند | انجام شده |
| **5** | **همان قواعد، یک کمپین ۴۰ نقطه‌ای را با هشت بازرس، کارگاه، مدارک، اعزام، بازدید، عدم انطباق و تسویه تا آخر می‌برند** | **وقتی `python -m validation.run_trl5` بدون خطا تمام شود** |
| 6 | روی سفارش واقعی، با بازرس و GPS و پرونده کارفرما | برآورده نشده |

## محیط مرتبط چیست

| شرط کار واقعی | این نسخه |
| --- | --- |
| بدون مدرک لازم، بازدید شروع نمی‌شود | گیت مدارک روی نقطه |
| بازدید حضوری فقط به بازرس متخصص، آنلاین و داخل شعاع می‌رسد | رتبه‌بندی |
| بازبینی مدارک می‌تواند از راه دور باشد | نقاط Review مدارک، شعاع را کنار می‌گذارند |
| دو بازرس یک نقطه را با هم برنمی‌دارند | پیشنهاد باز دیگر بسته می‌شود |
| اگر کسی نپذیرد، نقطه به صف آماده برمی‌گردد | انقضای پیشنهاد |
| بازرس باید واقعاً در کارگاه باشد | فنس ۰٫۸ کیلومتر |
| Hold و Witness عکس می‌خواهند | گیت شواهد |
| جوش یا تست مردود باید تعمیر و دوباره اعزام شود | NCR و بازدید دوم |
| بازدید مردود پول نمی‌سازد | دفتر تسویه فقط بعد از تأیید |

کمپین آزمایشگاهی همان مقیاس یادداشت محصول است: هشت بازرس و چهل نقطه، روی چهار تجهیز ثابت (مخزن، مبدل، اسپول، شاسی) در یک کارگاه.

## این سطح چه چیزی را ادعا نمی‌کند

- چک‌لیست‌ها رویه مصوب یک کارفرما نیستند و جایگزین ITP امضاشده پروژه نمی‌شوند.
- تعرفه و سهم ۱۸ درصد نمونه عملیاتی است، نه قرارداد.
- نقشه، طرح کرج تا قزوین است نه سرویس نقشه زنده.
- عکس تازه از دوربین مرورگر در `data/evidence` ذخیره می‌شود. اپ بومی موبایل ساخته نشده است.
- ورود نمایشی هویت سازمانی نیست.
- هیچ GPS، کارگاه یا بازرس واقعی در حلقه اعتبارسنجی نبوده است.

## مسیر TRL 6

1. یک سفارش واقعی با ITP امضاشده جایگزین قالب نمونه شود و همین معیارهای کمپین دوباره پاس شوند.
2. عکس و مدارک در مخزن فایل با نسخه و دسترسی نقش‌ها بنشینند.
3. ورود بازرس از GPS دستگاه، نه دکمه مختصات نمونه، فنس را رد یا قبول کند.
4. هویت کاربران به سامانه سازمان وصل شود و ارجاع دستی در سابقه ممیزی بماند.
