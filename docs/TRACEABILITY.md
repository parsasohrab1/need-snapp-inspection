# ردیابی خواسته به قابلیت

مبنا یادداشت‌های دست‌نویس «اسنپ بازرس» (ITP، اعزام شبیه اسنپ، IVR، MOM، مدارک خرید، موقعیت و هماهنگ‌کننده) است. فایل صوتی حدود ۵۸ دقیقه‌ای با مدل محلی گفتار به متن قابل اتکا تبدیل نشد و مبنای پیاده‌سازی قرار نگرفت.

| خواسته | پیاده‌سازی |
| --- | --- |
| ITP و نقاط Hold / Witness / Review / Surveillance | `app/domain/catalog.py` و نقاط هر تجهیز |
| مدل اسنپ: پیشنهاد به بازرس نزدیک و پذیرش یکی | `app/domain/matching.py` و `broadcast` / `accept_offer` |
| اپ بازرس | نمای گوشی در صفحه اعزام |
| مدارک خرید، گواهی، WPS، پکینگ، نقشه | گیت `missing_docs` |
| بازرسی از راه دور برای مدارک | `remote_allowed` و `start_remote` |
| IVR | `submit_visit` و صفحه گزارش |
| MOM | صورتجلسه‌ها |
| هماهنگ‌کننده و ارجاع دستی با دلیل | `force_assign` |
| عدم انطباق و بازرسی دوباره | `confirm_ncr` |
| موقعیت و محدوده کارگاه | فنس ۰٫۸ کیلومتر |
| هشت بازرس و چهل نقطه | داده نمایشی و کمپین `app/scenarios.py` |
| تسویه بازرس | دفتر `Ledger`، سهم ۱۸ درصد، ردِ بازدید مردود |
